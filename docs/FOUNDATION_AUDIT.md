# SolarSight foundation audit (phase 2)

Numbers come from `docs/analysis/foundation_report.md` (generated by `scripts/analyze_foundation.py`).

## Decision: READY WITH KNOWN GAPS

The candidate universe, metrics, project-size methodology and Pareto engine are defensible and
reproducible offline. The known gaps are FEMA flood, DEQ AEC polygons, site availability, old NWI
imagery and the thin landfill/quarry scenarios. All are disclosed in the data and do not block the
frontend.

## What changed after the EPA attribute-table discovery

* The local EPA geodatabase **already held every Mapper attribute**. `DataRecords.csv` is the same
  table: all 6,074 NC rows join 1:1 on Cross-Reference Number with identical values; the CSV only
  rounds PV capacity to 2 dp and adds `Solar Installation Potential`, which is `Y` for all NC rows.
  Nothing was re-downloaded.
* EPA becomes the **historical screening baseline** shown beside SolarSight analysis. It is no longer
  something SolarSight re-derives. EPA fields keep an `epa_` prefix and native units (miles, kV).
* The brownfield universe is now **NC DEQ project polygons**, joined to EPA by exact ID. OSM is only
  used for secondary (landfill) and exploratory (quarry) scenarios.
* Generation and capacity were demoted from objective to **context**. Project size is a user input
  (MW AC).
* The terrain objective changed from whole-site mean slope to **mean slope of the usable land**, to
  avoid double counting.
* "Mapped wetland" (phase 1) is now correctly named `osm_mapped_wetland_*`; the authoritative NWI
  metric is computed separately.

## Validated (shown with data/code)

| Item | Evidence |
|---|---|
| DEQ geometry | 1,363 polygons, unique `BF_Number`, 1 invalid in source (repaired, flagged), polygon area ≈ DEQ acreage (median ratio 1.00) |
| DEQ ↔ EPA identity | 973 of 973 EPA "NC Brownfield Projects" join a DEQ polygon by ID (high); +3 address/city (medium), +7 unique point-in-polygon (low), 3 ambiguous (no match chosen), 377 DEQ projects newer than EPA's snapshot (unmatched, kept) |
| EPA acreage semantics | EPA acreage = DEQ-reported acreage for 97.3% of ID matches; current polygon area within 10% of EPA acreage for 76.6%; 92 records differ by >50% (boundary changes, multipart amendments, tiny-site digitising) |
| Transmission distance | Pipeline equals an independent brute-force distance for 7 spot checks (max diff 0.000000 km). Polygon boundary to line, with 0 = a mapped line intersects the boundary (true for all 109 zeros). EPA's NC brownfield distances are also boundary-based, not point-based (13.6% exactly 0): vs SolarSight, median abs diff 0.007 km, Spearman 0.85, and both are 0 for 62 of 63 sites. From EPA's published point the fit is worse (0.20 km, Spearman 0.81). Large disagreements trace to definitions (EPA counts 66 kV / unknown-voltage lines) |
| Terrain | Horn slope in EPSG:32119, synthetic-plane tests, 100% DEM coverage of all 662 candidates |
| NWI | 98.8% of NC covered by NWI mapping projects; all 662 candidates covered; overlap computed on the 10 m grid |
| Solar model | PVWatts on NSRDB about 10% above observed NC fleet (92 plants); MWh per MW AC CV 2.0% across DEQ candidates |
| Pareto | Brute-force equality in every scenario; 39 unit/integration tests |

## Assumed (explicit, in `src/analysis/assumptions.py`)

| Assumption | Value | Basis |
|---|---|---|
| Capacity convention | project size in **MW AC** | planner/utility convention |
| Land density | 0.35 MW DC / usable acre = 0.28 MW AC / acre | LBNL 2019 fixed-tilt median (whole-plant footprint) |
| DC/AC | 1.25 | same LBNL medians |
| Acres for target | 5 → 17.9, 10 → 35.7, 20 → 71.4, 40 → 142.9 usable acres | derived |
| Slope rule | usable if pixel slope ≤ 10% (user may pick 5/15%) | product choice, sensitivity disclosed |
| NWI | NWI vegetated wetland not counted as usable (switchable) | screening convention, not jurisdiction |
| Built out | ≥ 25% building coverage → `likely_built_out` | product choice; observable |
| Grid filter | OSM `power=line` with voltage tag ≥ 69 kV | product choice; untagged excluded |

## Missing

| Gap | Severity | Handling |
|---|---|---|
| FEMA flood (NFHL) | should fix before demo if time allows; not blocking | `fema_flood_data_status="not_assessed"`, null overlaps |
| DEQ Areas of Environmental Concern | nice to have | not in repo; `aec_data_status="not_available"` |
| Site availability / ownership / current use | inherent; post-hackathon | DEQ status shown verbatim, building coverage, warnings |
| NWI currency (median imagery 1983) | disclosed | caption + warning |
| Landfill cell-level closure | post-hackathon | only 1 `likely_closed` + 5 `mixed` landfills; secondary scenario is thin |
| Grid capacity / hosting capacity / queue | never in scope | warning |
| Pavement / parking-lot detection | nice to have | building footprints only |

## Not represented (never claimed)

Interconnection capacity, queue position, connection cost, permitting approval, legal wetland
jurisdiction, flood risk, contamination severity, site availability or ownership, engineering
yield, investment ranking, or a single "best" site.
